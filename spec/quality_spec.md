# 文档转换质量规范 v1.0

> 适用于 MinerU-GLMBridge 输出质量校验与格式约定。
> 目标：保证转换后的 Markdown 结构完整、信息不丢失、可喂给 AI 使用。

## 五条质量铁律

1. **信息完整** —— 每页完整转换，不丢内容。full.md + images/ + json 全保留。
2. **结构还原** —— 标题层级、段落、表格、公式、代码块正确。
3. **文字准确** —— OCR 错别字降到最低（互补模式用 PaddleOCR）。
4. **图片保留** —— 图片存 `images/` 并正确引用，不丢失。
5. **隔离输出** —— 每文件独立子文件夹，不污染源目录。

## 输出结构规范

### 单块文件（≤200 页整本转换）

```
{原文件所在目录}/{原文件名}_mineru/
├── full.md          # Markdown 正文（含表格/公式/图片引用）
├── images/          # 提取的图片
├── layout.json      # 版面分析中间结果
├── _model.json      # 模型推理结果
└── _content_list.json  # 内容列表
```

### 多块大文件（>200 页拆分）

```
{原文件所在目录}/{原文件名}_mineru/
├── p1-190/          # 第 1-190 页
│   ├── full.md
│   └── images/
├── p191-380/        # 第 191-380 页
│   ├── full.md
│   └── images/
└── p381-555/        # 第 381-555 页
```

## 质量校验清单

转换后抽查 `full.md` 确认：

| 检查项 | 通过标准 |
|---|---|
| OCR 错别字 | 互补模式几乎无；纯 GLM 允许少量 |
| 表格 | 结构对齐，非纯文字堆积 |
| 公式 | LaTeX 可渲染，非乱码 |
| 标题层级 | `#`/`##`/`###` 正确 |
| 目录页码 | 与正文页码对齐 |
| 图片引用 | `![](images/xxx)` 有效，图片文件存在 |
| 每页内容 | 无整页空白/丢失 |

## 校验工具

```bash
# 抽查 md 大小（空文件=转换失败）
wc -c "{输出目录}/full.md"

# 检查图片是否提取
ls "{输出目录}/images/" | wc -l
```
